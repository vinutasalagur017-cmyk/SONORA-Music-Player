# SONORA — Working Music Player

A professional HTML/CSS/JavaScript music player with original generated demo audio.

### Features
Play/Pause, Previous/Next, Shuffle, Repeat, Playlist, Autoplay, Search, Progress Bar, Seeking, Volume Control and Responsive Design.

### Run
Open this folder in VS Code and use Live Server, or open `index.html` directly in a modern browser.

**Important:** Upload the complete `assets` folder to GitHub along with `index.html`.
